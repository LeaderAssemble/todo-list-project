📝 Todo List

A simple and user-friendly Todo List application that helps users manage their daily tasks efficiently. Users can add, edit, complete, and delete tasks, making it easier to stay organized and improve productivity.

---

✨ Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 📋 View all tasks in an organized list
- 💾 Save tasks for future use
- 📱 Responsive and clean user interface

---

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

---

📂 Project Structure

Todo-List/
│
├── index.html        # Main webpage
├── style.css         # Styling file
├── script.js         # JavaScript functionality
└── README.md         # Project documentation
